`ctx.fetch`, used ONLY behind `isEditablePath`. The file list uses `ctx.vault.listFiles`. `assertWritable` is an overlap guard.

## Exported signatures

```ts
interface WebEnv { adminToken: string | undefined; enabled: boolean; sessionTtlSec?: number /*3600, max 7200*/; maxBytes?: number /*200_000*/ }
handleWeb(req: Request, ctx: AgentContext, env: WebEnv): Promise<Response | null>;  // null = not a web path OR disabled
HUMAN_PREFIXES: readonly string[];  // ["Daily/","Plans/","Deadlines/manual/","Notes/"]
isEditablePath(path: string): boolean;
signSession(secret: string, nowSec: number, ttlSec: number, nonce?: string): Promise<{ cookie: string; csrf: string; expSec: number }>;
verifySession(secret: string, cookieValue: string | null, nowSec: number): Promise<{ ok: true; csrf: string; expSec: number } | { ok: false }>;
interface HumanVault { load(path: string): Promise<{ content: string; sha: string } | null>;
  save(path: string, content: string, baseSha: string | null, message: string): Promise<{ sha: string } | "conflict"> }
createHumanVault(ctx: AgentContext): HumanVault;
renderMindmap(i: { deadlines: { title: string; category?: string; dueAt: string }[]; tasks: { title: string; status: string }[]; notes: string[] }): string; // pure; job wiring is not P5
```

**`isEditablePath`:** string, <= 200 chars, NFC-stable, `isSafeRelativePath`, ends `.md`, no segment starting `.`, chars only
`[\p{L}\p{N} _.\-()/]` (no `%`, `:`, `\`, control, bidi), starts with a `HUMAN_PREFIXES` entry, not under `Plans/Proposed/`, and
`assertWritable(path)` throws. Case-sensitive.

**Session:** key = `hmacSha256Hex(adminToken, "brain-agent/web/v1")`. Cookie
`__Host-brain_sess=v1.<expSec>.<nonce32hex>.<sig>`, `sig = hmac(key, "v1.<exp>.<nonce>")`; attributes `HttpOnly; Secure;
SameSite=Strict; Path=/; Max-Age`. Verify with `timingSafeEqualHex`; reject bad shape, expired, or `exp - now > 7200`. Nonce = 16 random bytes. CSRF token = `hmac(key, "csrf|"+nonce)`, hidden field `csrf` in every POST form. Login compares
`sha256Hex` of both tokens with `timingSafeEqualHex`.

## Routes (only these match; all else `null`)

If `!enabled || !adminToken`: `null` for every path (kill switch, Worker's 404). All responses carry `cache-control: no-store`,
`nosniff`, `referrer-policy: no-referrer`, CSP `default-src 'none'; style-src 'unsafe-inline'; form-action
'self'; base-uri 'none'; frame-ancestors 'none'`. Internal error => generic 500 page.

| Route | Behaviour |
|---|---|
| `GET /login` | form (`password`). 200 |
| `POST /login` | urlencoded body cap 2 KB (413); same-origin check (403); rate limit; wrong 401 (no hint); right 303 `/edit` + cookie. Token only in body |
| `POST /logout` | valid session+csrf+origin: clear cookie, 303 `/login`; no session: 303. `GET`: 405 |
| `GET /edit` | no/expired session: 303 `/login`. Else 200 list of files under `HUMAN_PREFIXES` (`ctx.vault.listFiles`, filtered, max 300), links `/edit/file?path=<encodeURIComponent>`, plus a "new note" path form |
| `GET /edit/file?path=` | session (303); `!isEditablePath` 403; `load`; missing = create mode (empty `sha`). 200 form: hidden `path`,`sha`,`csrf`, `<textarea name=content>`; `?saved=1` notice |
| `POST /edit/save` | order: session (401) -> Origin present must equal `url.origin`, else `Sec-Fetch-Site` must be `same-origin`, neither => 403 -> csrf (403) -> body > `maxBytes`+4 KB (413) -> `isEditablePath` (403) -> content string, no NUL (400), <= `maxBytes` (413), CRLF->LF -> unchanged vs loaded? 303 no write -> `save(path, content, sha\|\|null, "web edit: <path>")`; `"conflict"` => 409 page keeping the user's text + reload link; success 303 `/edit/file?path=..&saved=1`. Other methods: 405 with `allow` |

**Rate limit:** key `web:rl:<floor(nowSec/900)>` via `ctx.store.kvGet/kvSet`; >= 5 failures => 429 + `retry-after` BEFORE comparing. Global; sessions unaffected; `kvGet` throws => 503.

**HumanVault:** `load` = `GET /repos/{repo}/contents/{encPath}?ref={branch}`, 404 => null, base64 UTF-8 decode, blob `sha`. `save` = `PUT` same URL `{message, content: base64, sha?, branch}`; `baseSha===null` = create-only.
409/422 => `"conflict"`; other non-2xx throws `GitHub API <status> on <what>` (no body/token). `repo` must match `^[\w.-]+\/[\w.-]+$`.
GitHub-side compare-and-swap: a file changed since load is never overwritten.

## Threat model

| Threat | Mitigation |
|---|---|
| Brute force of ADMIN_TOKEN | 5 fails/15 min, 429 before comparison |
| Token leak | body only, never logged, `no-referrer`, generic errors |
| Cookie theft / XSS | HttpOnly, Secure, `__Host-`, zero JS, strict CSP |
| Forgery / replay | HMAC over exp+nonce, expiry checked, TTL 1 h (max 2 h) |
| CSRF | SameSite=Strict + Origin/Sec-Fetch-Site + per-session token |
| Traversal, dotfiles, `.obsidian/` | `isEditablePath`; path never touches a filesystem |
| Clobbering agent files (Tasks/, Digests/, Plans/Proposed/) | prefix allowlist + `assertWritable`-must-throw |
| Lost update vs agent/Obsidian commit | sha CAS => 409, text preserved |
| XSS via content/path | escape `& < > " '` everywhere, `encodeURIComponent`, no inline JS, CSP |
| Left exposed | off unless `EDIT_ENABLED=1` AND `ADMIN_TOKEN`; else `null` |
| Access unavailable | cookie login is the baseline; Access is optional |
