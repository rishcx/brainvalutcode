**Ships:** behind `chat.engine: "v3"`: exact commands stay instant; every other message goes through ONE JSON

## Flow of `runAgent` (each numbered step inside `timed(trace, "<stage>")`)

1. `load`: `Promise.all([loadDialog, turnsForDay, kvGet(summaryKey)])`.
2. `fast`: `isCancelWords` + active dialog -> `clearDialog`, "OK, cancelled. Nothing was set." `parseFast` hit ->
   run it (status/tasks via existing replies with `who`; `done` bare -> `lastDelivered` -> close; `snooze` ->
   `snoozeReminder` on the index or last delivered; `cancel <n>` -> `closeReminder(dismissed)`; `trace`). Bare
   `done`/`cancel` with nothing to act on falls through to PLAN.
3. `dialog`: active dialog with `asked === "when"` and `pureTimeAnswer(text)` (the time phrase consumes the whole
   message except fillers `ok|at|on|by|please|then`) -> fill, execute the pending tool, no LLM.
4. `plan`: no brain -> `degraded("no-brain")`. `brain.complete({ system, prompt, responseFormat: "json_object",
   maxTokens: 350, temperature: 0, cacheTtlMs: 0, purpose: "plan", timeoutMs: chat.perAttemptMs })`;
   `entry === "deterministic"` -> `degraded("unreachable")`; `parsePlan` null -> one more call if elapsed < 3 s,
   else `degraded("unparseable")`.
5. `tools`: validated calls in order; mutating tools get `env.sources` = current text + `dialog.sources`
   (never memory). A result with `missing` -> save dialog (intent, slots, missing, asked = missing[0],
   sources + text, questions + 1, CAS on version) and reply `question(asked)`; questions > 3 -> clear +
   "I still need <slot>..." Completed mutation -> row `{intent:"idle", missing:[], lastAction}`, expiry +10 min.
6. `compose` only when (`search_notes` or `github_involvement` ran, or `plan.compose` with a list tool) and the
   read returned data; failure -> the code render.
7. Reply = `say` (smalltalk/help/unsupported only) or renders joined by `\n` or compose text -> `formatChat`,
   `redactSecrets`, cap 1,500. Record user + assistant turns. Fill the trace (route, intent, toolsJson
   `[{name, ok, note}]`, flags, replyChars, preview). Return `{ reply, trace }`.
8. After the reply is built (still in `runAgent`, budget permitting < 15 s): `memory.ts#refreshSummary` when
   un-summarised older text > 2,000 chars (one call, `purpose: "summary"`, failure keeps the old summary).

## PLAN prompt (`plan.ts`) - system <= 3,600 chars, whole prompt <= 7,500

System: who/now/tz/weekday; the tool list with arg shapes (PLAN_V3 B.3 table); output contract
`{"intent","tools":[{"name","args"}],"say","compose"}`; rules: (1) string args `what`, `when_text`, `items[].text`,
`ref.text` are **copied verbatim** from the user's words, (2) a slot the user did not give is `null`: never guess,
never take it from memory, (3) `say` never states data, counts, times or that something was done, (4) greeting/thanks
-> smalltalk, one short sentence, no data, (5) unsupported -> say so, (6) plain text. 4 few-shot pairs: `set a reminder`
-> create_reminder{what:null,when_text:null}; `add milk, eggs and gym` -> add_tasks 3 items; `what are today's tasks`
-> list_tasks{day:"today"}; `no, make it 7pm` + LAST ACTION -> reschedule_reminder{ref:{last:true},when_text:"7pm"}.
Prompt: `fence(memory)` (summary <= 400 + last 6 turns <= 1,200 chars), `fence(dialog JSON)` or `none`, LAST ACTION
line, `fence(message)` (<= 1,000). **No notes, no task/issue titles, no snapshot.**

## Tools (code-rendered replies)

- `create_reminder`: `what` must pass `spanOk` (else missing) -> tidy (strip leading `to|about|that|for|me to`).
  Time: `parseRelativeWhen(when_text)` ?? `parseLooseWhen(when_text)` (date-only -> `dueHourLocal`); else `at_local`
  if `hasTimeToken(sources)`; disagreement > 60 s -> parser wins + flag `time_disagree`; past -> missing when with
  "That time has passed." Bare hour "at 6" -> next future 06:00/18:00. Create via `createReminder({..., explicit:
  true, id: "chat:<msg.id>:<toolIndex>", origin: who})` (two reminders in one message must not collide). Render `Reminder set: <what>, today 15:15 (in 10 min).`
- `reschedule_reminder` / `cancel_reminder` / `snooze_reminder`: `Ref` -> `last` = `dialog.lastAction` or
  `lastDelivered`; `index` -> per-channel list; `text` -> open chat deadlines whose normalised title contains the
  span; 0 -> "I couldn't find a reminder matching ..."; > 1 -> ask which (numbered, persisted).
- `add_tasks`: each `items[].text` span-checked (failures listed: "I skipped 'x' because ..."), `addTask`; render
  `Added 3 tasks: milk; eggs; gym.` / `Already on your list: gym.`
- `complete_task`/`drop_task`: index or span; ambiguous -> numbered question.
- `list_tasks`/`list_deadlines`/`list_reminders`: render `Today (3 open):` + `• ` lines (<= 8, then `... and n more`),
  persist numbering with `who`; empty -> `No tasks for today.` etc.
- `github_involvement`, `search_notes`: return data; compose renders; empty -> honest line
  (`I couldn't find that in your notes.`).

`compose.ts`: system = style guide (PLAN_V3 B.6) + "answer ONLY from TOOL RESULTS; if they do not answer, say so";
prompt = message + `fence(results)` (<= 3,000 chars); plain text; `maxTokens 300`; output never parsed.

## Edge cases

Junk/prose JSON; last object with `intent` wins; > 4 tools / > 10 items truncated + flagged; unknown tool
dropped; `index` 0 or beyond the list; dialog CAS conflict (reload once, else continue without dialog); topic switch
keeps the dialog + one nudge line; expired dialog; two reminders same title; IST day boundary for "today";
"tomorrow 12am"; message 10 KB (capped); empty message -> help line.

## Security

Mutations only from spans of `sources` (current message + dialog answers). PLAN prompt holds no untrusted bulk data;
COMPOSE has no tools. Every untrusted block through `fence()`/`cleanText`. Refusals become questions + trace flag
`provenance_miss:<slot>`, never silent.
