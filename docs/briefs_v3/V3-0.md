## 5. Scheduler (`dispatch.ts`)

```ts
export function nextRunAt(schedule: Schedule, after: Date, tz: string): Date {
  if ("everyMinutes" in schedule) {
    const M = 60_000;   // whole minute + interval, never completion + interval
    return new Date(Math.floor(after.getTime() / M) * M + schedule.everyMinutes * M);
  }
  return nextLocalTimeAfter(after, tz, schedule.dailyAtLocal);
}
```
`runDueJobs`: `ensureJob` only when `kv("jobs:specHash")` differs from the joined spec names (then set it).

## Edge cases

- Dialog CAS: two `putDialog(..., 3)` -> one true. `null` over an unexpired row -> false.
- Two claims on the same ids -> disjoint; a stale claim can be re-won; wrong-claim `finishReminder` is a no-op.
- `bumpUsage` twice sums; absent optionals keep old values. `listTrace` clamps 1..200.
- Legacy rows read back `originChannel: null`, `attempts: 0`.
